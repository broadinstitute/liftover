Lift over variants, positions, or intervals from one reference genome to another.
more info...
This web interface supports more input formats and requires fewer clicks than existing interfaces like UCSC LiftOver and Ensembl Assembly Converter.

Under the hood, it uses the UCSC liftOver command-line tool for intervals and positions, while for variants it uses a new bcftools plugin which avoids many of the limitations of other liftover tools (particularly for indels) as described in [Genovese 2024]. All chain files were downloaded from UCSC.

We use the GeneBe API to convert HGVS notation to genomic coordinates for hg38, and to provide variant consequences for both hg19 and hg38. The Ensembl API is still used to convert HGVS notation for hg19, and as a fallback when GeneBe cannot convert an HGVS variant.

To submit issues or feature requests, please use broadinstitute/liftover/issues.


Input formats:
chr8:141310715
chr8:141310715 T>G
NM_001089.3(ABCA3):c.875A>T (p.Glu292Val)
chr8:141310715-141310720
more formats...

  • Positions:
    chr8:141310715
    chr8-141310715
    chr8   141310715
  • Variants:
    chr8:141310715 T>G
    chr8-141310715-T-G
    NM_001089.3(ABCA3):c.875A>T (p.Glu292Val)
  • Intervals:
    chr8:141310715-141310720
    chr8   141310715   141310720
The "chr" prefix is optional, and separators can be :, -, >, or space(s).
